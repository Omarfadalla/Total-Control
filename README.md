# Total Control
- An endless bicyle game build with Godot, featuring Alex- a teenager wondering around the world- on his bicycle. he will pass through different backgrounds and collect coins on the way*

## About
- Ride along with Alex as he pedals through and adventure world , collecting coins along the way.

## Features
- Endless gameplay: the world keeps going
- coin collection: pickup coins scattered along the way
- Background music & pickup sound effects
- main menu & settings: start, adjust, options, exit

## Build with
- Godot Engine

## Controls(QWERTY)
- move left: left arrow key or D key
- move right: right arrow key or Q key

## Getting Started
- Install Godot 4.6+
- Clone the repositoryt
- Open the project folder via in Godot via project to import
- press Run(F5) to play from the main menu
